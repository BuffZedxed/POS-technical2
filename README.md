# POS Technical 2

A simple Point-of-Sale (POS) system created using **CodeIgniter 4** and **MySQL** for Laboratory Activity 2.

## Hosted Application

https://pos-technical2.rf.gd/

https://pos-technical2.rf.gd/about

https://pos-technical2.rf.gd/customers

https://pos-technical2.rf.gd/users

## Features

* Home page
* About page
* Customer Accounts
* User Accounts
* MySQL database integration
* Customer records retrieved from the database
* User records retrieved from the database

## Pages

* `/` - Home
* `/about` - About
* `/customers` - Customer Accounts
* `/users` - User Accounts

## Database

The project uses a MySQL database named `pos_db`.

### Tables

**customers**

* id
* full_name
* email
* phone
* created_at

**users**

* id
* username
* full_name
* created_at

The database export is included in:

`pos_db.sql`
